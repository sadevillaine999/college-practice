**Версия 2.0 (lite)**

---

### 1. Общие сведения

**1.1. Назначение**  
Настоящий документ предназначен для владельца / администратора приложения «TopMessenger Lite». Описаны принципы работы с локальным хранилищем, управление данными пользователя и настройка интерфейса.

**1.2. Состав комплекса**

- Мобильное клиентское приложение (Flutter, Android / iOS).
    
- Локальное хранилище данных (в памяти устройства).
    
- Отсутствие серверной части и внешних API.
    

**1.3. Особенности версии**  
Полностью автономное приложение. Все данные (профиль, сообщения, настройки) хранятся только на устройстве пользователя. Администраторская функция — управление исходным кодом и сборкой приложения.

---

### 2. Требования к среде администрирования

- Установленный Flutter SDK (версия 3.x).
    
- Android Studio / Xcode (для сборки под iOS).
    
- Устройство или эмулятор для тестирования.
    
- Git (для управления версиями исходного кода).
    

---

### 3. Управление локальными данными

**3.1. Структура хранилища (класс `LocalData`)**

|Поле|Тип|Описание|
|---|---|---|
|`currentUser`|Map|Имя, email, bio текущего пользователя|
|`darkMode`|bool|Состояние тёмной темы|
|`_messages`|Map<String, List<String>>|Сообщения по чатам|

**3.2. Предустановленные чаты**

- `favorites` — «Избранное» (2 приветственных сообщения).
    
- `notes` — «Заметки» (2 приветственных сообщения).
    

**3.3. Сброс данных до заводских**  
Удалить приложение и установить заново.  
Либо очистить кэш приложения через настройки ОС.

### 4. Настройка темы оформления

**4.1. Параметры темы**

|Параметр|Светлая тема|Тёмная тема|
|---|---|---|
|Фон|Белый|Чёрный|
|Цвет линий|Чёрный|Белый|
|Цвет акцентов|Синий|Синий (Accent)|
|Текст|Чёрный|Белый|

**4.2. Переключение темы**  
Пользователь переключает через настройки. Администратор может изменить тему по умолчанию в коде:

dart

// файл local_data.dart
bool darkMode = true; // false — светлая тема по умолчанию

**5.1. Изменение приветственных сообщений**  
Файл: `local_data.dart`, конструктор `LocalData._internal()`:

dart

_messages = {

  'notes': ['Заметка 1', 'Заметка 2'],

### 6. Сборка и распространение

**6.1. Сборка APK (Android)**

bash

flutter build apk --release

Выходной файл: `build/app/outputs/flutter-apk/app-release.apk`

**6.2. Сборка IPA (iOS)**

bash

flutter build ios --release

Затем открыть `Runner.xcworkspace` в Xcode и выполнить Archive.

**6.3. Обновление иконки приложения**  
Заменить файлы в папке `assets/launcher/` и выполнить:

bash

flutter pub run flutter_launcher_icons:main

### 8. Безопасность (локальная)

**8.1. Ограничения**

- Данные хранятся в открытом виде в памяти приложения.
    
- При удалении приложения данные теряются безвозвратно.
    
- Нет шифрования сообщений.
    

**8.2. Рекомендации для администратора**

- Не хранить реальные пароли или личные данные в предустановках.
    
- При распространении приложения предупреждать пользователей о локальном характере хранения.

### 9. Частые проблемы и их решение

|Проблема|Решение|
|---|---|
|Сообщения не сохраняются после перезапуска|Проверить, что `LocalData` — синглтон, данные не пересоздаются|
|Тёмная тема сбрасывается|Проверить вызов `LocalData().darkMode = val` в `SettingsScreen`|
|Не прокручивается к новому сообщению|В `ChatScreen` добавить `_scrollToBottom()` после `addMessage`|
|Кнопка отправки неактивна|Проверить `_messageController.text.trim().isNotEmpty`|
|Аватар не отображается|Убедиться, что `CircleAvatar` получает первую букву из `currentUser['username']`|
