# Примечание о доступе

На территории Российской Федерации сервис Telegram официально заблокирован Роскомнадзором.

Для доступа использовались:

- VPN на iPhone
- встроенный MTProto Proxy на Desktop

Это условие тестирования отражает пользовательский сценарий для аудитории из России.

# TG-001 — Hidden Story Bug

## Описание

После скрытия истории пользователя новое кольцо Stories отображается, однако нажатие по нему ничего не делает.

## Платформа

- iPhone 13 Pro
- iOS 26.5
- Telegram iOS 12.7

## Шаги воспроизведения

1. Скрыть истории пользователя
2. Пользователь публикует новую историю
3. Нажать на кольцо Stories

## Фактический результат

История не открывается.

## Ожидаемый результат

История должна открываться или отображать меню «Показывать истории».

## Статус

Open

# TG-002 — GIF Trim Bug

## Описание

При обрезке GIF перед отправкой Telegram отправляет оригинальный GIF без изменений.

## Шаги воспроизведения

1. Открыть GIF
2. Выбрать обрезку
3. Отправить

## Фактический результат

Отправляется полный GIF.

## Ожидаемый результат

Должен отправляться обрезанный фрагмент.

## Статус

Open

# TG-004 — Sticker Scroll Lag

## Описание

При наличии более 20 пакетов стикеров наблюдались лаги при прокрутке.

## Статус

Closed (исправлено в Telegram iOS 12.7)

# Выводы

По результатам тестирования:
