---

### 1. Введение

**1.1. Полное наименование**  
Мобильное приложение «TopMessenger» для обмена сообщениями в реальном времени.

**1.2. Заказчик**  
Частное лицо / стартап-проект.

**1.3. Основание для разработки**  
Решение о разработке собственной закрытой системы обмена сообщениями для мобильных устройств на Android / iOS.

**1.4. Назначение**  
Приложение обеспечивает регистрацию, аутентификацию, текстовый чат «один-на-один» через WebSocket, управление контактами и профилем, смену пароля, загрузку аватара, настройки интерфейса.

**1.5. Технико-экономические обоснования**  
Снижение зависимости от сторонних мессенджеров. Полный контроль над данными пользователей и серверной логикой. Возможность масштабирования на бизнес-среду.

---

### 2. Требования к программе

#### 2.1. Требования к функциональным характеристикам

**2.1.1. Аутентификация и учётная запись**

- Регистрация по email + username + password (мин. 6 символов).
    
- Вход по email + password.
    
- Выход из аккаунта с очисткой токена и кэша.
    
- Автоматическое обновление сессии по истечении токена (заглушка).
    

**2.1.2. Профиль пользователя**

- Просмотр и редактирование: username, email, bio (до 256 символов).
    
- Выбор статуса («Доступен», «Не беспокоить», «Офлайн», «Встреча», «В отпуске»).
    
- Загрузка аватара из галереи.
    
- Смена пароля с проверкой текущего.
    

**2.1.3. Контакты**

- Просмотр списка контактов.
    
- Добавление контакта по email.
    
- Удаление контакта.
    
- Поиск пользователей по строке запроса.
    

**2.1.4. Чат**

- Открытие диалога из контакта.
    
- Загрузка истории сообщений.
    
- Отправка / приём сообщений через WebSocket.
    
- Автоматическое переподключение при обрыве связи (задержка 3 с).
    
- Визуальное разделение «моих» и «чужих» сообщений.
    

**2.1.5. Настройки**

- Вкл/выкл уведомлений.
    
- Тёмная / светлая тема.
    
- Скрытие/показ онлайн-статуса (UI-заглушка).
    

**2.1.6. Фон и анимация**

- Анимированные движущиеся точки с линиями.
    
- Адаптация под размер экрана (до 60 точек на мобильных устройствах).
    
- Реакция на курсор при наведении (Web-версия не требуется, но оставлено).
    

**2.1.7. Кэширование и производительность**

- Хранение ответов API на 5 минут.
    
- Ограничение частоты запросов: не более 5 в секунду.
    
- Retry-механизм (до 3 попыток, экспоненциальная задержка).
    
- Приоритет кэша при `cacheOnly=true`.
    

---

#### 2.2. Требования к надёжности

- При разрыве WebSocket — попытка восстановления каждые 3 секунды.
    
- При 401 Unauthorized — принудительный выход на экран логина.
    
- Обработка всех ошибок с человекочитаемым текстом.
    
- Отсутствие крашей при неполных данных от сервера.
    

---

#### 2.3. Условия эксплуатации

- ОС: Android 6+ / iOS 12+.
    
- Интернет: Wi-Fi / 4G / 5G.
    
- Серверная часть: `http://91.214.78.192`, `ws://91.214.78.192`.

1. Разработана архитектура на Flutter (Dart).

6. Выполнена интеграция с бэкендом (REST + WebSocket).
